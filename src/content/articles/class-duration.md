**Пара — 1 час 30 минут**: два академических часа по 45 минут без перерыва. Учатся с понедельника по субботу.

| Пара | Очная и заочная | Очно-заочная (вечер) |
|---|---|---|
| 1 | 9:00–10:30 | |
| 2 | 10:40–12:10 | |
| 3 | 12:20–13:50 | |
| 4 | 14:30–16:00 | |
| 5 | 16:10–17:40 | |
| 6 | 17:50–19:20 | 18:20–19:40 |
| 7 | 19:30–21:00 | 19:50–21:10 |

Между 3-й и 4-й парой — большой перерыв на обед, 13:50–14:30.

Занятия бывают лекциями, семинарами, практическими и лабораторными. Расписание группы — в личном кабинете и на странице «Расписания» сайта вуза.
